# 1.0.34：AI 对话布局与中文文案

本次按用户要求不执行宿主功能测试或真机交互测试；仅完成构建、打包、签名和安装。运行包仍为 1.0.30。

## 变更

- 顶部并排显示带背景的工程名和对话名；对话名取第一条提问，长标题缩略并保留完整悬停提示。
- 新建、切换、设置、浮窗按钮移到第二行。上下提问箭头放到聊天区域顶部，透明背景、半透明箭头，不随消息滚动。
- 移除主界面删除按钮。切换工程窗口中，右键已有对话可删除；中文确认框提醒工程文件保持不变。
- AI 置顶窗口标题改为“AI对话”；向导入口改为“中文校对”；校对完成状态只保留建议数量。
- 精简 AI 设置中的视觉与 Shell 文案；权限行为保持不变，Shell 默认关闭。具体能力边界仍见 AI-UX-1.0.33.md。
- AI / 中文校对侧栏仅显示图标，补偿竖向标签栏造成的旋转；名称保留为悬停提示。
- 工程切换、设置和删除确认的主要按钮显式使用中文。

## 安装后由用户检查

1. 打开虎鲸侧栏，点 ⇄ 选择工程及对话，观察两块名称背景和第二行按钮。
2. 发两条消息，使用聊天区域顶部半透明箭头切换提问位置；滚动时箭头应留在顶部。
3. 点 ⇄，右键一条不需要的测试对话，选“删除对话”；先取消，再按需确认删除。
4. 点 ⚙ 查看中文按钮和简化文案；点 ▣ 查看标题“AI对话”及置顶行为。
5. 打开向导 → 中文校对，完成后查看建议数量；检查左侧两个图标方向和无文字效果。
