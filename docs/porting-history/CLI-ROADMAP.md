# CLI 应开放到什么程度

**1.0.25 进展：** 工程目录授权、非模态面板、文件分页列表、缓冲区读取、TeX 打开/主文件切换、会话内 20 项任务历史、增量日志、有限诊断、同目录 PDF 摘要已实现并限定验收，见 `PROJECT-CLI-1.0.25.md`。下面保留完整目标设计；多工程同会话授权切换、resource.find、PDF 页数、跨重启任务持久化和受控写入仍未实现。

2026-09-25，基于 1.0.23 实现及 1.0.24 能力查询。

目标是让本地 AI 完成“选择工程→检查→修改→构建→诊断→验证 PDF”的循环。1.0.23–1.0.24 使用固定当前主文档的构建会话；以下保留完整接口设计，实际交付范围以各版本报告和 capabilities 返回为准。

## 工程范围

用户在应用中选一个工程根目录，并开启会话。连接文件只授权这个目录，关闭会话失效。多工程可切换已授权根目录；不能通过 `../`、绝对路径或符号链接访问根目录外文件。应用私有的全局资源、密码、API Key 不进入文件接口。

首批优先开放：

| 接口 | 返回/行为 |
|---|---|
| capabilities | 版本、协议、可用功能及限制；已实现基础版本 |
| project.info / files.list | 根目录、主文件、文件树，列表分页 |
| documents.list | 已打开文件、主文件、未保存/冲突状态 |
| document.open / master.set | 打开工程内文件、切换主文档；已有未保存编辑不被覆盖 |
| document.read | 指定行范围、文本编码、当前编辑缓冲区版本和磁盘哈希 |
| build / cancel / job.status | 指定主文件和引擎，返回持久的 job ID |
| job.logs / diagnostics | 增量日志、错误/警告、文件与行号；保留原始日志 |
| artifact.info | 该任务对应的 PDF 路径、哈希、生成时间、页数；区分旧 PDF |
| resources.list / resource.find | 查询生效资源和文件来自哪一层，不暴露凭据 |

第二批增加受控写入：`document.create`、`document.applyEdits`、`document.save`。每次提交带版本号或旧哈希，不匹配就拒绝；通过编辑器的撤销系统修改，不从磁盘绕过未保存缓冲区。AI 批量修改先展示差异，再一次应用。新建文件限制在授权工程，保存失败必须返回明确错误。

第三批：白名单构建缓存清理、PDF 页图导出、源/PDF 定位、资源包导入计划与提交。清理依据当前任务清单和明确后缀，保留源文件及已有 PDF，不能照单执行不可信 `.fls` 中的任意路径。

不提供默认的任意 shell、系统目录读写、账户密钥读取、无确认删除工程、自动安装原生二进制。这些功能会把应用工程接口变成系统终端，却不能提高应用构建结果的可信度。HiShell 自身已有终端能力，可以在其权限范围内处理通用工作。

## 需要一起解决的工程问题

- 当前会话是模态窗口；工程级 CLI 应迁移到应用生命周期内的服务对象，用非模态面板显示授权范围和任务，避免打开文档受模态窗口阻挡。
- 任务不能只保留最后一次全局状态：按 job ID 保存有限历史，日志按 offset 增量读取，取消必须校验 job ID。
- 编译成功、PDF 是否是本次产物、页面视觉是否正确是三个不同结果。需要记录编译前后产物摘要，不能凭屏幕存在 PDF 判定成功。
- 诊断文本路径必须规范化到工程；命令模板和引擎使用枚举，不能拼接客户端提交的 shell 字符串。
- 分别测试跨目录中文路径、未保存编辑、外部磁盘修改、忙碌、取消、路径穿越、符号链接、会话撤销和旧 PDF。

建议下一次实现首批工程接口及任务记录，随后再开放写入；当前 UI 修复版不同时扩大文件写权限。

## 外部终端

当前桌面版入口会查找 Linux 终端程序，鸿蒙上实际得到 `<unknown>`。HiShell 是另一个 Ability，不能把包名填进桌面命令栏就当成可执行文件。

本机已核对 HiShell 的公开声明：EntryAbility 有文件类型入口，但未发现可直接照用的 `hishell://` 命令协议。因此目前可用方法仍是手动打开 HiShell，在公共工程目录运行引擎，或通过本应用 CLI 请求应用内构建。公共 HNP 引擎可以直接使用；应用私有用户资源要通过应用 CLI 使用，或导出副本配置搜索路径。

下一步的“在终端打开工程目录”应使用鸿蒙 Ability 桥接，并在应用身份下验证目标应用接收目录、权限与返回错误。HDC 的 `aa start` 是调试入口，不能作为普通应用已接通终端的证明。平台 URI 唤起规则参考：https://developer.huawei.com/consumer/en/doc/harmonyos-guides/app-uri-config 。
