# 1.0.35：Markdown 与对话排版收尾

应用 1.0.35，运行包仍为 1.0.30。按用户要求，仅构建、签名和安装，不运行宿主功能测试或真机交互测试。安装状态见 `validation/workbench-1.0.35/device-result.json`。

## 操作

- AI 设置（⚙）新增“对话字号”“输入字号”，均默认 10 磅，可在 7–24 磅之间分别调整，立即应用并记住设置。
- 拖动聊天记录与输入区之间的横向分隔条，上下调整输入区高度；记住分隔位置。仍支持 Ctrl+Enter 发送。
- 工具调用及文件修改提示使用对话字号减 1 磅；上下内边距缩小。连续记录使用同一个背景表格，中间无独立卡片空白；每条仍可单独折叠/展开。
- 回复、流式文字和恢复的历史消息使用同一 Markdown 转换：标题、粗体/斜体/删除线、代码块/行内代码、列表、引用、分隔线、表格和链接。

## 实现范围

Qt 5.12 没有 QTextDocument::setMarkdown，新增 `harmonymarkdown.h` 将常用 Markdown 转成 Qt 支持的富文本；不是完整 CommonMark 实现。原始 HTML 按文本显示；图片只显示替代文字，不自动加载远程图片；LaTeX 数学公式不在聊天中排版，仍需工程编译预览。HTTP/HTTPS/mailto 链接点击后交给系统处理。

已保存会话仍存储原始消息，未迁移或改写旧消息。改动不涉及 AI 服务配置、密钥、工程文件或 TeX 引擎。

## 用户检查建议

1. 让 AI 回复包含标题、列表、代码块和表格的短文，检查流式及完成后的显示。
2. 调整两种字号，检查工具记录比对话正文小 1 磅。
3. 拖动输入区上方分隔条，检查输入空间和聊天空间变化。
4. 查看连续工具调用及修改记录，确认背景合并且仍能逐条展开。

本轮未执行功能测试，构建成功不代表以上交互已通过真机验收；由用户检查后决定收尾。
