# 1.0.33：工程对话、窗口和编译产物查看

应用 1.0.33；HNP 仍为 1.0.30，本次没有更换 TeX 引擎或宏包资源。最终验收记录见 `validation/workbench-1.0.33/device-result.json`。

## 操作入口

- 左侧 **虎鲸** 打开工程对话，**带问号的放大镜** 打开中文校对。
- AI 右上角 **⇄**：先选择最近使用的工程，或打开其他工程；再选择该工程的历史对话或新对话。必须先选择工程才能发送。**＋** 新建当前工程的对话，**×** 删除当前对话记录，不删除文件或撤销修改。
- **⚙** 设置自动上下文、文本修改、视觉、Shell 和删除权限。模型、服务地址与密钥仍在「设置 TeXstudio → 语言检查 → AI」中。编辑、Shell、删除权限切换工程或重新打开历史后重置；视觉选项和自动上下文偏好保存在本机。
- **▣** 将 AI 放到独立置顶窗口，再点一次或关闭窗口会还原到侧栏。输入框支持普通粘贴和 Ctrl+Enter。输入法仍在组词时，应先完成文字上屏。
- 对话中「你」使用浅色背景，「回复」使用白色；工具调用是独立折叠记录，点击展开查看详情或修改前后文本。上下箭头跳到上一条/下一条提问。流式刷新保留正在阅读的位置；位于底部时跟随回复，发送新消息时定位到底部。
- 中文校对结果栏右侧 **⛶** 展开为覆盖编辑区和 PDF 的大窗口，关闭或再次点击可还原；使用同一结果列表，不重新发送校对请求。

## 工具与权限

| 能力 | 行为 |
| --- | --- |
| `list_files` / `read_file` | 工程内允许类型的文本；优先读取已打开的编辑器缓冲区 |
| `replace_text` / `create_file` | 默认关闭；保持版本校验、精确替换和新建不覆盖。已打开文件留在编辑器撤销历史，未打开文件原子保存 |
| `read_log` | 读取工程 `.log` 尾部最多 96 KB，附修改时间；不是对最新构建成功的承诺 |
| `view_pdf` | 需启用视觉且模型支持图像。读取指定工程 PDF 的指定页，应用使用 Poppler 实际渲染为 JPEG，发送 Chat Completions 的 `image_url` 内容；附页码、页数和修改时间。不会自动编译 |
| `shell_start` / `shell_status` | 默认关闭。应用权限内执行 `/system/bin/sh`（其他平台回退 `/bin/sh`），工作目录为当前工程；异步执行、30 秒限制、输出保留末尾 64 KB，返回运行状态和退出码 |
| `delete_file` | 默认关闭。仅处理未打开的允许类型文本，要求匹配读取时的 revision，移动到工程 `.texstudio-ai-trash/`，返回恢复位置；不会直接抹除文件 |

Shell **不是工程文件系统沙箱**：启用后可执行应用权限允许的命令，包括批量修改和删除；文本工具的扩展名限制不约束 Shell。只在需要时主动启用。回收目录可通过显示隐藏文件的终端/文件管理器恢复，暂未提供独立回收站界面。Shell 超时/停止会尝试终止自己的子进程组；不保证能够限制主动脱离进程组的任意程序。

PDF 单文件限制 50 MB，页图长边最多 1536 像素、JPEG 最多 1 MB。图像会随记录对话设置保存在本地会话文件中；删除对话会删除对应本地记录。服务是否支持图像必须按模型验证，启用选项不会让纯文本模型自动获得识图能力。较长对话有上下文上限，必要时新建对话。

## 反色修复与测试范围

旧版仅恢复 QApplication 全局调色板，不能覆盖 QPA 后续设置的控件类别调色板。新版本在主题、调色板和窗口显示事件后恢复浅色控件调色板，保留局部样式表；显式粘贴路径也作延迟恢复。密钥始终遮蔽，测试不读取或导出用户密钥。

- 宿主文件工具测试：路径、符号链接、只读、版本校验、日志边界、禁止删除打开文件、回收内容一致性、能力开关。
- Qt 界面测试：必须选工程、Ctrl+Enter、保持滚动和跟随底部、提问导航、工程权限重置、Shell 输出、浮窗内容可见与还原。
- 调色板模拟：应用及控件类别调色板覆盖后恢复、后续创建控件恢复。
- 真机测试与候选包差异以 `device-result.json` 为准。真实 DeepSeek 文本请求与读取经过验证；图像输入协议采用本地模拟服务核对，尚未验收真实视觉模型的识图质量。本轮不是全量 TeX/所有输入法/所有多窗口模式回归。

构建验证：WSL 运行 `build-support/test-workbench.sh`、`test-ui33.sh`、`test-palette33.sh`、`build-workbench.sh`；Windows 运行 `assemble-workbench-package.py` 和 `sign-with-deveco.py --version 1.0.33`。一次性 `upgrade-workbench33.py` / `integrate-workbench33.py` 是迁移记录，不应重复执行。
