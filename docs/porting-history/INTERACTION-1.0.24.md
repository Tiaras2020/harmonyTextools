# 1.0.24 界面、资源管理与 CLI 范围

2026-09-25。应用版本 1.0.24，运行包复用已验收的 1.0.21，本次没有重编 TeX 引擎。

## 交付内容

- 移除菜单的冲突样式规则，由 Fusion 同时测量功能名与快捷键列，避免两列重叠。
- 设置窗口按字体和可用屏幕调整初始大小；导航、快捷键表头与说明文字重新布局。
- Tabular 向导的表格列填满可用宽度，行高与字号协调，减少空白并保证底部按钮可见。
- 离线资源、用户资源、CLI 会话窗口调整默认大小。资源操作集中到操作按钮与右键菜单。
- 用户资源以目录树展示，支持 Shift/Ctrl 多选、新建文件夹和选中目录的批量删除。删除前确认；源工程不在资源树内。
- 新增“导入 ZIP（保留现有资源）”：验证后在暂存目录合并，路径冲突拒绝整个导入，保留原资源。“从 ZIP 恢复”仍是替换整个用户层，二者不能混用。
- ZIP 必须符合本项目用户资源包协议并带清单，不能直接导入任意上游源码 ZIP。保留 tex、doc、fonts 等标准资源路径；未实现目录重命名、移动或拖放。
- CLI 新增 capabilities，返回当前文档范围、命令清单、词典及 HTTPS 编译能力。工程级接口为下一阶段设计，见 [CLI-ROADMAP.md](CLI-ROADMAP.md)。
- 应用图标将浅色背景层替换为深紫色渐变，保留原 TeX 前景图案。旧 HAP 文件的图标不会随新安装包变化。

## 词典与 AI

首次没有配置词典目录时，自动提取随程序内嵌的 en_US.aff/dic 到应用数据目录并选择 en_US；不覆盖用户已有词典设置。真机已显示 en_US 及有效目录。尚未单独做拼写错误标注的端到端验收。

同义词数据独立于拼写词典。本次将上游 th_en_US_v2.dat 放在设备 `~/Download/LuaCli23/th_en_US_v2.dat`，在设置中选择该文件，输入 happy 实际显示 glad、blessed、cheerful 等结果，随后取消，未替换用户正文。此文件不在 HAP 内；移动或删除后需重新配置。未声称中文词典或外部语法服务器可用。

实际 Qt 构建配置包含 QT_NO_SSL、QT_FEATURE_ssl=-1、QT_FEATURE_opensslv11=-1。因此当前云端 HTTPS AI 接口不可用，填写 Key 不能解决。本版在发出请求前给出明确提示。保留自定义 OpenAI 兼容地址入口，但没有获得用户服务地址、没有读取或填写 Key，也没有测试本地 HTTP 模型服务。后续需另做 Qt TLS 适配及证书验证。

## 外部终端

当前“外部终端”仍沿用桌面终端探测，真机结果为 unknown。不能把 HiShell 包名当可执行程序填进去。本次核对目标应用声明，未发现可以直接采用的命令 URI；没有实现应用身份下的 Ability 桥接。

目前可以手动打开 HiShell 使用公共引擎，或者通过已有 texstudioctl 会话调用应用构建。应用私有用户资源不会自动共享给 HiShell：使用应用构建接口，或导出资源并配置终端搜索路径。具体桥接和项目级 CLI 的方案见 CLI-ROADMAP.md。

宿主资源 API 原有 17 项与新增 6 项合并测试通过；新增覆盖保留原文件、TDS 目录、空目录、冲突回滚、穿越/核心资源保护和符号链接拒绝。资源对话框语法检查、ARM64 应用编译、HAP CRC、原运行包摘要和签名校验通过。
