## 其他功能边界

- AI 未实现上下文自动摘要/压缩；请求体大小限制不是 token 预算。
- Markdown 为常用富文本子集，没有聊天数学排版、远程图片自动加载。
- 视觉工具传送已存在 PDF 的页图，不代表刚执行过编译。
- 用户资源不会天然同步到任意外部终端环境；公共 HNP 与应用私有用户层要区分。
- 多平台输入、长时间运行、弱网络、所有宏包/字体均未全量验证。
- 开发签名包受 profile/设备限制；原私钥未随仓库保留。

历史修复记录不能推翻本页新的用户复现报告，尤其不要把较早生命周期修复等同于 BUG-002 已关闭。

## 迁移时发现的源码分歧

Windows 工作副本曾有 `LatexDocument::isHidden/getListOfDocs` 生命周期保护，但旧同步清单漏掉 latexdocument.cpp，WSL 实际构建源未包含此改动。仓库主源码保留实际构建版本；候选修复另存 `patches/unreleased/document-lifetime-guards.patch`，未应用、未验证，不等于 BUG-002 已修复。后续开发需独立评审和复现测试。
