# 功能与使用

## 编辑与编译

打开 `.tex`，选择正确根文档与引擎。中文一般使用 XeLaTeX 或 LuaLaTeX；具体宏包/字体是否可用按项目验证。多文件工程使用主文档组织，暂留意 KNOWN-ISSUES 中多工程显式主文档关闭崩溃。

内置预览支持 PDF 浏览与 SyncTeX 定位；外部鼠标、触控板与手指行为存在不同平台边界。构建失败时先读日志；旧 latexmk 失败记录可用“清理构建缓存并重新编译”或 CLI build.clean 恢复，保留源文件。

## 三层资源

1. 基础/完整版 HNP：默认随本体预装兼容运行资源，包含可执行引擎和发行资源。
2. 附加离线资源：导入包解压到资源目录，导入完成后无需一直保留原 ZIP；再导入或迁移时应另备份。
3. 用户资源：自定义宏包、字体、Lua/文本资源，支持目录管理、启停、导入导出。修改的是环境搜索层，不是直接重编引擎。

不要假定所有 TeX Live 平台二进制均可直接用于 HarmonyOS。资源导入的兼容筛选不等于全生态验收。资源恢复/替换前保留用户自定义内容。

## 中文与字典

设置 → 语言检查中可选择 zh_CN。本地词典覆盖不等于语义错别字纠正。中文校对按钮检查选区或全文，通过配置的 LanguageTool 服务处理正文，结果在底部独立页，可放大。在线校对会向该服务发送文本。

## AI 对话

点虎鲸图标 → ⇄ 选择工程 → 新建/打开对话。首行显示工程与会话名，右键会话名可重命名；会话列表右键支持改名/删除。删除对话不会撤销工程文件修改。

⚙ 中设置上下文、读写/视觉/Shell/删除权限及对话/输入字号；▣ 切换置顶窗口。Ctrl+Enter 发送，拖动输入区分隔条调高；顶部箭头跳转上一/下一条提问。工具记录默认折叠。

模型、地址、密钥在设置 → 语言检查 → AI 中配置。密钥在设备输入，不写入工程或仓库。AI 服务是否支持工具/图像按服务验证。编辑、Shell、删除权限默认关闭或切换工程时重置。Shell 是应用权限，不是工程目录沙箱。

## 安装与迁移

签名 HAP 已包含 HNP。升级前保存未保存文档与用户资源；新签名可能要求卸载旧包，卸载通常会失去应用私有设置/会话，因此先按需导出。源码 clone 不会包含个人项目或应用私有会话。
