GitHub 迁移的恢复检查会单独记录在 `recovery-validation.json`：它只验证指定环境下从仓库及附件恢复的构建，不是重新运行平板交互或所有 TeX 引擎/宏包验收。

本仓库不包含个人讲义、真实 API 密钥或 CLI 会话令牌。历史文档中的个人路径、缺失附件引用仅用于理解实施过程，不是当前下载清单；当前附件以 recovery-assets.json 为准。
